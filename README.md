# Anuj Yogesh Joshi — Portfolio Website

A personal portfolio website for **Anuj Yogesh Joshi** (TY BTech • Software Developer & Engineer based in India).

Featuring a tech-creative aesthetic inspired by Figma canvas tools, interactive resume tabs, services showcases, dynamic project cards, and 1-click WhatsApp communication.

## 🚀 Built With
- **HTML5**: Semantic, accessible markup
- **Vanilla CSS3**: Custom design tokens, neobrutalist shadows, responsive layout, Figma handle motifs, and smooth animations
- **JavaScript**: Tab switcher, hover preview interactions, and copy feedback
- **Zero build dependencies**: Runs immediately in any browser

## 📱 Features
- **Hero Showcase**: Headshot portrait with solid offset drop shadow, rotating circular badge, and action CTAs.
- **Infinite Ticker Ribbon**: Smooth continuous scrolling of developer capabilities (Software Engineering, C++, Python, Web Development).
- **Segmented Resume Tabs**: Seamlessly toggle between Education (TY BTech), Developer Skills (C++, Python, HTML, CSS), and Experience.
- **Services Showcase**: Service list with cursor-following mockup preview.
- **Project Grid**: Real-world project showcase cards with category tags.
- **Direct WhatsApp & Phone Contact**: 1-click WhatsApp link and clickable phone dialer.

## 💻 Running Locally
Simply open `index.html` in any web browser, or serve using Python:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.
